TradeMind brand assets
=======================

Drop the generated 3D logo image here with this exact name:

    trademind-logo.png

/public/logo3d (the animated brand page) renders the vector mark inline from
/public/logo.svg, so it stays crisp at any size — the PNG is not required there.
The PNG below is still used by the app header and the sign-in screen.

Recommended: a square PNG (e.g. 1024x1024) with a transparent background.
