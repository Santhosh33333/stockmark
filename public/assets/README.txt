TradeMind brand assets
=======================

Drop the generated 3D logo image here with this exact name:

    trademind-logo.png

/public/logo3d (the animated logo page) loads /assets/trademind-logo.png first.
If that file is missing it automatically falls back to /logo.svg, so the page
never shows a broken image.

Recommended: a square PNG (e.g. 1024x1024) with a transparent background.
