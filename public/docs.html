Getting started

TradeMind is a web application. Open the app, sign up with your email and a password, and you land in the workspace in paper-trading mode — no real orders, no card required.

  1. Use the global search or the Scanner to find setups.
  2. Open a symbol to read its market structure and overlays.
  3. Check multi-timeframe alignment and the risk/reward box.
  4. Run a Backtest to see how the rules performed historically.
  5. Practise in Paper Trading before ever connecting a real broker.

Methodology

The strategy is fully deterministic and documented. A BUY setup is confirmed when all of the following are true on the analysis timeframe:

  • Wick rejection — a long lower wick rejecting a level, on above-average volume.
  • Unmitigated order block — the rejection happens at a bullish order block that has not yet been mitigated.
  • Inducement sweep — price sweeps a prior low (liquidity) before reversing.
  • 4H RSI filter — the resampled 4-hour RSI is below the configured threshold.

Each setup is then confluence-scored (0–100) from independent factors: fresh signal, active zones, structure, fair-value gaps, liquidity, EMA position, volume and RSI. The same function runs live in the scanner and in the backtester, so results are reproducible.

Multi-timeframe confirmation

Weekly, daily, 4H and 1H are each reduced to an UP / DOWN / RANGE bias from market structure (BOS/CHoCH) and EMA. The alignment is reported as a weighted score so a trade is only taken when the higher timeframes agree.

Every source is free to use. Yahoo Finance is unofficial and may throttle, so Angel One / Fyers can be added as faster primary sources. If a provider is unreachable the app shows an explicit “unavailable” state — it never substitutes a placeholder or stale value presented as live.
Credentials for the optional sources are stored server-side in data/providers.json (never committed, never sent to the browser). Only the owner can view or change them.

Paper trading

Paper positions are simulated: entry, stop-loss and take-profit are stored, and Check SL/TP evaluates them against live prices. Realised and unrealised P&L, win rate, profit factor and max drawdown are computed from the paper book only. Paper trading never contacts a broker.

Options analytics

The option chain supports indices (NIFTY, BANKNIFTY, FINNIFTY, MIDCPNIFTY, …) and F&O stocks. Each strike shows LTP, change, open interest, OI change, implied volatility and volume for calls and puts, plus PCR and total OI. Fields the provider does not supply are shown as — rather than guessed. When a Dhan token is saved the Dhan chain is used; otherwise the free NSE feed is used.

Dhan live execution (optional)

Create a free DhanHQ account, generate an API access token and client id in the Dhan dashboard, and save them in Settings → Dhan. Credentials are stored server-side and never sent to the browser. Until a valid token is present the app stays in paper mode. The API base is https://api.dhan.co/v2.

TradingView alerts

Download the matching Pine Script at /smc-strategy.pine and add it to TradingView. Point the alert webhook at your TradeMind instance to record alerts in the app.
